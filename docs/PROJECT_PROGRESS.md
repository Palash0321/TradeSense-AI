# 📌 TradeSense AI - Project Progress

## Project Overview

TradeSense AI is an AI-powered stock market analysis platform designed for Indian and US stock markets.

The objective is to provide traders with intelligent trade recommendations using technical indicators, AI analysis, explainability, portfolio management, paper trading, and market analytics.
