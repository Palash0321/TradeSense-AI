# 📈 TradeSense AI

> AI-Powered Stock Market Analysis Platform for Indian & US Markets

TradeSense AI is a modern stock market intelligence platform that combines technical analysis, AI-driven trade recommendations, market analytics, interactive charts, and portfolio management into a single application.

The goal of this project is to help traders and investors make better decisions using explainable AI instead of relying solely on raw technical indicators.

---

# 🚀 Features

## 📊 Stock Analysis

- Live stock price analysis
- Interactive candlestick charts
- AI-generated BUY / HOLD / SELL recommendations
- Confidence scoring
- Support & Resistance detection
- Risk / Reward calculation
- Trade planning
